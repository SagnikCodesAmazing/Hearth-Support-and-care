## How to Add a Custom Skill
If you need a skill that is not provided by default, you can create one:

1. **Create a skill definition** – a markdown file placed in `.claude/skills/` (or any directory referenced via `skills.path` in settings). The file should contain:
   - A short description.
   - Optional arguments (`args`).
   - The actual behavior (usually a prompt that instructs the agent on what to do).

2. **Reference the skill** – invoke it with:
   ```
   /skill-name
   ```
   or via the `Skill` tool:
   ```json
   {
     "skill": "skill-name",
     "args": "optional arguments"
   }
   ```

3. **Document it** – add an entry to this `AGENTS_AND_SKILLS.md` file under “Custom Skills” so that future contributors know what is available.

## How to Add a Custom Agent
Custom agents allow you to encapsulate a specific workflow with a predefined set of tools, model choice, and optional background execution.

1. **Create an agent definition** – a JSON or YAML file under `.claude/agents/` (or as configured by `agents.path`). Example:
   ```json
   {
     "name": "code-reviewer",
     "description": "Reviews diffs for style and potential bugs",
     "model": "sonnet",
     "tools": ["Read", "Edit", "Grep", "Glob"],
     "prompt": "You are a careful code reviewer..."
   }
   ```

2. **Use the agent** – invoke with the `Agent` tool:
   ```json
   {
     "description": "Run custom code reviewer",
     "prompt": "<your prompt here>",
     "subagent_type": "code-reviewer"
   }
   ```

3. **Record it** – add a description to this file under “Custom Agents”.
